# BeerTeam
Назва проєкту — ЗдайВчасно.



Опис — сайт для відстеження студентських завдань і дедлайнів.



Основні функції — додавання завдань, збереження, сортування за дедлайнами, позначка «Здано».



Технологічний стек — HTML, CSS, JavaScript, localStorage (якщо команда його затвердила).



Команда — PM, Frontend, Backend, Designer, QA.



Запуск проєкту — як відкрити сайт локально.
